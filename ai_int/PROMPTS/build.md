# Use this when: building a new feature or page

Read `README.md`, `PROJECT.md`, and `RULES.md` first if you haven't already this session.

## Steps to follow

1. **Look before you build.** Check if this project already has something similar (a component, a page, a pattern). Reuse it instead of creating something new that duplicates it.
2. **Plan in 3-5 short sentences**: what you're building, which files you'll touch, any assumption you're making. Show me this before writing code.
3. **Build it**, following every rule in `RULES.md`.
4. **Test it yourself** using the browser — actually click through the feature, fill out any forms, try weird/edge-case input (empty fields, huge input, refreshing mid-action).
5. **Self-check:**
   - Works on mobile width too?
   - No secrets/console.logs left in?
   - Handles the empty/loading/error state, not just the happy path?
   - Would a wrong/malicious input break anything?
6. **Report back:** what you built, what you tested, and anything you weren't sure about.
