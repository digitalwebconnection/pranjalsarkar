# AI Prompt Notes

> For anything UI-related, give a reference instead of describing it in words: a screenshot of a similar layout, or a link to a site whose style you like. "Make it look modern" is vague; a reference image removes the guesswork and gets you closer to what you actually pictured on the first try.

## Tips for prompting AI coding assistants on this project

- **Be specific about the section**: reference the component name (e.g., `HeroSection.tsx`, `DiagnosisSection.tsx`) rather than describing the section by its content.
- **Include the file path**: when asking for edits, mention the full path like `frontend/src/components/sections/HeroSection.tsx`.
- **Attach reference images**: screenshots of layouts you like are worth 1000 words of description.
- **State the design constraints**: dark mode, specific color palette, animation style, etc.
- **Mention the tech stack**: this project uses React, TypeScript, Vite, Framer Motion, and vanilla CSS — be explicit so the AI doesn't suggest incompatible approaches.
